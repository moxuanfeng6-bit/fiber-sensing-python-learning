## 学习内容

### NumPy：数组与数值计算

- 创建一维、二维和三维数组。
- 理解 `shape`、`size`、`ndim` 和 `dtype`。
- 使用索引、切片和布尔条件选择数据。
- 练习数组运算、广播、形状调整和排序。
- 计算均值、中位数、标准差、分位数和四分位距。
- 使用 `argmin()`、`argsort()` 等方法定位数据。

### Pandas：实验数据整理

- 创建和使用 Series、DataFrame。
- 区分标签索引 `.loc` 与位置索引 `.iloc`。
- 读取和导出 CSV、JSON 等数据。
- 转换数据类型，处理缺失值和重复记录。
- 新增计算列，按条件筛选、排序。
- 转换日期时间，按时间范围截取记录。
- 使用 `groupby()` 和 `agg()` 汇总重复测量数据。

### Matplotlib：数据可视化

- 绘制折线图和散点图。
- 设置标题、坐标轴、图例、网格和显示范围。
- 使用多个子图比较数据。
- 标注光谱最低点，展示拟合与插值结果。
- 绘制三维曲面和三维轨迹。
- 保存分析图像。

### SciPy：科学计算方法

- **优化与拟合**：最小二乘拟合、函数最小化、初始值与约束的影响，以及 Nelder–Mead、共轭梯度和 BFGS 方法。
- **方程求解**：使用 `root()`、`fsolve()` 求根，使用 `linalg.solve()` 求解线性方程组。
- **插值**：比较线性、最近邻和三次插值，练习样条、RBF 和二维网格插值。
- **线性代数**：初步学习行列式、特征值、特征向量和 SVD。
- **积分与微分方程**：梯形法、`quad()`、`dblquad()` 和 `odeint()`。
- **信号处理**：一维与二维中值滤波、FFT、频率筛选和逆傅里叶变换。

## 综合练习

### 1. 光谱寻谷与误差分析

生成带有共振谷的模拟光谱，并完成：

- 截取指定波长范围。
- 计算局部光强统计量。
- 查找最低光强及其对应波长。
- 比较检测波长与设定中心波长。
- 将误差从 nm 换算为 pm。
- 绘图标注检测结果。

### 2. 稀疏光谱插值与定位

使用稀疏采样点建立线性和三次插值函数，在密集网格上重新寻谷，并比较不同方法的定位误差。

练习重点：插值可以增加查询位置，但不会增加真实测量信息，曲线更平滑也不代表一定更准确。

### 3. 传感器线性标定

使用模拟浓度与波长漂移数据，建立模型：

```text
波长漂移 = k × 浓度 + b
```

通过最小二乘公式、`leastsq()` 和最小化残差平方和等方式估计参数，并绘制拟合曲线与残差图。

### 4. 实验数据清洗与分组统计

对模拟实验记录进行类型转换、缺失值处理和去重，计算波长漂移，再按浓度、日期等字段汇总，导出结果并绘图。

### 5. 光谱谷面积与响应过程

- 使用梯形法和 `quad()` 计算相对基线的光谱谷面积。
- 比较采样点数对离散积分结果的影响。
- 使用 `odeint()` 模拟传感器响应，比较不同时间常数下的响应速度。
- 使用线性方程组区分浓度变化与温度变化的影响。

### 6. 傅里叶变换与频率分离

构造低频和高频正弦信号，完成：

1. 在时域观察原始信号和混合信号。
2. 使用 FFT 计算频域系数。
3. 根据采样间隔建立频率坐标。
4. 观察频率和振幅变化对频谱的影响。
5. 通过频率条件分别保留低频、高频成分。
6. 使用 IFFT 还原时间波形。
7. 计算还原误差，检查结果。

练习重点：傅里叶变换改变信号的表示方式；修改频域系数才是滤波操作。


## 运行注意事项

- 部分单元格依赖前面定义的变量，请先阅读上下文，再按顺序运行。
- 修改信号或参数后，需要重新计算依赖它们的结果。例如：

  ```text
  修改信号 → 重新计算 FFT → 滤波 → 逆变换 → 计算误差
  ```

- 部分文件读写示例依赖本地数据文件，需要根据实际位置调整路径。
- 中文绘图示例使用了 `Microsoft YaHei`，其他系统可能需要更换字体。
- `scipy.datasets.face()` 首次读取示例图片时可能需要联网。
- 不同版本的库可能存在接口差异，例如使用 `np.trapezoid()` 替代旧的 `np.trapz()`，二维网格插值使用 `RectBivariateSpline()` 替代已移除的 `interp2d()`。
