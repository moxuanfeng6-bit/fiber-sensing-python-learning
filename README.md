练习主要使用 Jupyter Notebook（`.ipynb`）记录。每份练习尽量包含：

2. 自己编写的代码。

文件会随着学习进度逐步上传，文件名以实际上传内容为准。

## 运行方式

当前练习需要 Python、NumPy，以及能够运行 Jupyter Notebook 的环境。

如果尚未安装相关工具，可以运行：

```bash
python -m pip install numpy notebook
```

下载仓库中的 `.ipynb` 文件后，在 Notebook 编辑器中打开，选择已安装 NumPy 的 Python 环境，按顺序运行代码单元。
